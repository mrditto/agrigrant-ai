# Judge Share Package

Use this page as the quick handoff for 4-H judges.

## Project

AgriGrant AI is a Streamlit app that helps farmers browse a curated set of agricultural grant opportunities in a simple interface.

## Share links

- GitHub repository: `https://github.com/mrditto/agrigrant-ai`
- GitHub Pages landing page: `https://mrditto.github.io/agrigrant-ai/`
- Live Streamlit app: `ADD-YOUR-STREAMLIT-URL-HERE`

## What judges should do

1. Open the live Streamlit app.
2. Review the available grants shown in the interface.
3. Click a grant title to open the official funding source.
4. Use the GitHub link if they want to review the code.

## Security note

The public website is static and contains no API keys. Any future secrets should remain in Streamlit secrets or environment variables and never be committed to GitHub.

## Short description

AgriGrant AI was built to make agricultural funding opportunities easier to browse and understand for farmers by collecting grant information into one simple experience.
