How to access it

Use this GitHub Pages site as the public homepage, then send users into the live app with the main button above.

Why this is safer

GitHub Pages is static, so anything placed there is public. Sensitive API keys should live only in server-side environment variables or Streamlit secrets.

Before you publish

  • Replace YOUR-APP.streamlit.app with your deployed app URL.
  • The GitHub source link is already connected to the real repository.
  • Configure app secrets in your hosting provider, not in the repo.

Good rules for API safety

  • Never commit secret keys to GitHub.
  • Never expose keys in frontend JavaScript.
  • Read secrets from host-managed environment variables.

Recommended setup

  • Public site: GitHub Pages
  • Live Streamlit app: Streamlit Community Cloud
  • Secrets: st.secrets or environment variables
